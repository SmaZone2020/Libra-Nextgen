# 部署与构建

## 环境要求

| 组件 | 要求 |
| --- | --- |
| Rust | 1.80+ |
| .NET SDK | 10（service 与 common） |
| Node.js | 20+（webapp） |
| MongoDB | 7.0+（Server 数据存储） |
| zig（可选） | 交叉构建载荷时由服务端自动调用 |

## 本地启动

```bash
# 1. Server（http://localhost:5270）
cd src/service
dotnet run

# 2. Console（http://localhost:5173；首次访问 /setup 创建管理员）
cd src/webapp
npm install
npm run dev
```

Server 启动后：连接 MongoDB、注册 JWT 密钥、开放 `http://localhost:5270`。Console 通过 `VITE_API_BASE`（默认 `http://127.0.0.1:5270`）访问 API。

## Builder 在线构建载荷

Console 的 **Builder** 页用于在线构建 Agent 载荷。产出位于 `src/build-output/`：

```
build-output/
├── agent.exe / agent 等载荷产物
└── modules/{x64,x86,linux-x64}/*.dll|.so     # Agent 云载模块（按需下载源）
```

- **Win x64 / Win x86**：MSVC 原生编译（Windows 上需 VS Build Tools + Rust MSVC 工具链）
- **Linux x64**：原生编译（rustc 默认工具链）
- **交叉构建**：服务端自动探测 **zig + cargo-zigbuild** 并调用；缺失时给出明确提示

```bash
# 交叉构建所需工具（两侧平台都需要）
cargo install cargo-zigbuild
# 下载 zig（https://ziglang.org/download）并加入 PATH
```

> 命令行本地构建 `cargo build --release` 只产出本机平台载荷；交叉构建请走 Builder 或手动 `cargo build --target ...`。

## 云载模块

内置模块（`build-output/modules/<platform>/`）：`shell`、`recon`、`creds`、`files`、`powershell`、`proxy`、`script`（Rhai 引擎）。Agent 首次使用时按需下载，**内存加载零落盘**。

**插件模块（native 插件）的 stage 流程**：
1. 插件导入/启用时，`PluginService.StageModules` 把 zip 内 `module/<platform>/*.dll|.so` 复制到 `build-output/modules/<platform>/`
2. Agent 执行插件动作时按 `module.name` 下载对应 dll

> ⚠️ **重新构建/重建 `build-output` 后，插件 dll 可能被清掉**，此时插件动作会报 `module download failed: 404`。两种恢复方式：
> - 插件管理页把插件**禁用再启用**（触发重新 stage）
> - 或手动把 `examples/<plugin>/module/x64/*.dll` 复制回 `build-output/modules/x64/`

## MongoDB / 配置要点

- 服务端默认配置见 `src/service/appsettings*.json`：连接串、JWT 密钥、监听地址
- 首次启动自动建索引；`AuditLogs` 只增不删（审计强制）
- 部署生产环境时：更换 JWT 密钥、监听非回环地址、反向代理 + TLS

## 插件仓库（Libra-Plugins）

独立仓库（非主仓库子目录）维护插件市场：
- 根目录放 `*.zip`，**不要手工编辑** `index.json`
- 改 zip 后推到 main，CI 运行 `build-index.ps1` 自动重建 `index.json` 并提交
- Console「插件市场」直连 GitHub raw（`VITE_PLUGIN_MARKET_BASE` 可覆盖地址），索引浏览器缓存 1 小时

## 常见问题

| 症状 | 处理 |
| --- | --- |
| 插件动作 `module download failed: 404` | 插件 dll 未 stage：禁用再启用插件，或手动复制 dll 到 `build-output/modules/<platform>/` |
| Agent 一直显示离线 | 检查 Mongo 连接、server 端口、Agent 心跳间隔；Server 重启后 Agent 会自动重新注册 |
| Builder 交叉构建失败 | 确认 zig 与 cargo-zigbuild 已安装且在 PATH |
| Console 网络错误 | 确认 `VITE_API_BASE` 指向 Server；若 Console 是 https，API 需同源或走代理/允许跨域 |
