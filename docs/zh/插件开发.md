# 插件开发教程

插件以 **zip 包**交付，在 Console **插件管理页** 导入/启用。完整示例与详细字段见 [`examples/plugin-sdk/README.md`](../../examples/plugin-sdk/README.md)（保姆级教程）。

## 插件的三层结构

| 层 | 位置（zip 内） | 作用 | 何时需要 |
| --- | --- | --- | --- |
| **Agent 模块** | `module/` | 在目标机器执行采集/操作 | 需要调用 Agent 能力 |
| **前端页面** | `page/` | Console 里的 UI | 需要自定义展示/交互 |
| **服务端逻辑** | `service/` | 服务端自定义接口（当前沙箱未加载，占位） | 预留 |

## zip 结构

```
plugin.zip
├── meta.json          # 插件契约（必需，zip 根目录）
├── module/            # Agent 端模块
│   ├── xxx.rhai       #   script 通道（免编译，推荐）
│   ├── x64/xxx.dll    #   native 通道（按平台分目录：x64/x86/linux-x64）
├── page/index.tsx     # 前端页面源码（HeroUI）
├── service/           # 服务端逻辑（占位）
└── assets/            # 静态资源（经 /api/plugins/<pluginId>/assets/<文件> 服务）
```

## meta.json 契约

```jsonc
{
  "schemaVersion": 1,
  "pluginId": "com.example.xxx",   // 仅字母/数字/. /- /_，建议反向域名
  "name": "插件名",
  "version": "1.0.0",
  "author": "libra",
  "description": "一句话描述",
  "entry": {
    "route": "xxx",          // 页面路由 /plugins/xxx
    "label": "nav.xxx",      // i18n 键
    "icon": "Puzzle",        // @gravity-ui/icons 图标名
    "apiRoot": "/api/plugins/com.example.xxx"
  },
  "i18n": { "zh": { "nav.xxx": "插件名" }, "en": { "nav.xxx": "Plugin" } },
  "actions": [
    {
      "action": "collect",          // 动作名（前端 dispatchTask 用）
      "label": "采集",              // 按钮文案
      "method": "POST",
      "argsSchema": {               // 参数 JSON Schema
        "type": "object",
        "properties": { "capability": { "type": "string", "title": "能力名" } },
        "required": []
      },
      "module": {
        "kind": "script",           // script=Rhai / native=cdylib
        "name": "xxx",              // .rhai 文件 stem 或 .dll/.so 文件名
        "op": "collect",            // 注入模块输入 JSON 的 op
        "entry": "main"             // script 入口函数（默认 main）
      }
    }
  ]
}
```

## Agent 通道

### script（Rhai，推荐）

`module/xxx.rhai` 入口 `fn main(args)`，`args` 是服务端组装的输入（含 `op`），返回 Map/字符串作为结果：

```rust
fn main(args) {
    let op = if args.contains("op") { args["op"] } else { "all" };
    let out;
    #if(WINDOWS)
        out = cmd("whoami");                 // Windows：CMD
    #elif(LINUX)
        out = shell("uname -a");             // Linux：/bin/sh
    #else
        out = "unsupported";
    #endif
    #{ "op": op, "out": out }
}
```

`#if(WINDOWS)/#elif(LINUX)/#else/#endif` 在**解析前**裁剪，非本平台分支不会进入引擎。平台 API 速查：

| 通用 | Windows | Linux |
| --- | --- | --- |
| `fs.read/write/list/exists` | `cmd` / `powershell` | `shell` / `bash` |
| `proc.list()/kill(pid)` | `reg_query/set/delete` | `uname` / `hostname` |
| `env.get` / `whoami` / `log` | `ipconfig` / `wmic` / `tasklist` | `ip_route` / `ss` / `dns` |

### native（cdylib）

`module/<platform>/xxx.dll|so` 导出（`libra-load` ABI）：

```rust
#[no_mangle] pub extern "C" fn module_name() -> *const u8 { concat!("xxx\0").as_ptr() }
#[no_mangle] pub unsafe extern "system" fn module_main(
    input: *const u8, input_len: usize, output: *mut u8, output_cap: usize) -> usize { … }
```

`module_name` 必须与 `meta.json` 的 `module.name` 一致（自校验）；输入输出均为 UTF-8 JSON。

## 前端接入

`page/index.tsx` 是源码分发（运行时无法编译 .tsx）：需放入 `src/webapp/src/plugins/<pluginId>/index.tsx` 并重建前端（`import.meta.glob` 构建期收集）。页面用宿主能力：

```tsx
import { usePluginHost } from '../../hooks/usePluginHost';
export default function MyPage() {
  const { selectedAgent, dispatchTask } = usePluginHost();
  const run = async () => {
    const res = await dispatchTask('com.example.xxx', 'collect', { capability: 'whoami' });
    console.log(res.result);   // Agent 返回的 JSON
  };
  // HeroUI 组件自由使用（Button/Card/Table/Accordion/Modal/Tabs…）
}
```

`usePluginHost()`：`selectedAgent` / `selectAgent` / `dispatchTask(pluginId, action, args?, agentId?)` / `subscribeOutput(cb, action?)` / `lastOutput`。

## 插件市场（Libra-Plugins）

- 独立仓库存放 `*.zip` + `index.json`（`pluginId/name/version/author/description/file/size`），CI（GitHub Actions）在 zip 变化时自动重建索引
- Console「插件市场」直接从 GitHub raw 拉取 index.json（localStorage 缓存 **1 小时**），一键安装 = 下载 zip → 走导入流程
- `index.json` 由 `build-index.ps1` 生成，**不要手工编辑**

## 导入方式

| 方式 | 说明 |
| --- | --- |
| **上传插件** | 选 zip 包导入并启用 |
| **从 Git 导入** | 输入 Git 链接，服务端 `git clone` 到插件目录，**以仓库名为 pluginId**（仓库根需有 meta.json） |
| **插件市场** | 从 Libra-Plugins 索引一键安装 |

## 开发须知

1. `meta.json` 必须在 zip **根目录**，键名 camelCase（`pluginId`/`argsSchema`）
2. `pluginId` 只允许 `[A-Za-z0-9.\-_]`；文件名/资源名走白名单校验
3. script 通道改脚本即生效（重新导入/重启后 Agent 按需下载）；native 通道要重新编译 + **重启 Agent 丢弃内存缓存**，且若重建过 `build-output` 需把插件 dll 重新 stage 到 `build-output/modules/<platform>/`
4. `argsSchema` 只做表单与轻校验，真正的输入校验在脚本/模块里做
5. 中文/多行返回值用 JSON 序列化，避免手工拼字符串出错
